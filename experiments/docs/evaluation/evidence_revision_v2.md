# 第二轮：证据质量检查与题集修订草稿

日期：2026-09-20。目标是阻止已知证据问题被一次模型满分掩盖，并保留可追溯的修订版本。本轮仅离线处理已有公开来源材料，未调用外部 API，新增费用 0 元，不记录姓名、密钥或私有配置。

## 已实现

- 新增证据质量检查：图表/曲线来源结合趋势类提问时提示可能依赖视觉；记录初轮筛查失败及后续复核分歧；保留助手发现和回答质量问题。
- 检查状态只有 `needs_review` 和 `no_flag_detected`。后者仅表示当前规则未发现问题，不能解释为医学正确或人工审核通过。
- 另存 60 题 v2 草稿，其中改动 3 题。图表题改问图例明确写出的厚度、填充率和相互作用假设；测量题明确限定为 2018 年教材中的两种约定；另一题收窄参考答案措辞。
- 已改题删除旧措辞对应的自动审核字段，防止沿用失效判断。所有题仍为 `reviewed:false`，明确标记为 AI 草稿。
- 原有 60 题及 dev/eval 冻结文件均未修改。检索漏召回案例保持原样。v2 是看过原评测结果后的回归草稿，不作为独立测试集；没有为改题沿用旧回答分数。
- 本地复核页新增检查状态及 v2 草稿展示，可与原题、原回答和证据对照。

## 文件与复现

- `src/evaluation/evidence_gate.py`：筛选规则与状态。
- `scripts/build_evidence_revision.py`：离线生成检查记录、v2 草稿及摘要；发现目标文件已被改动时拒绝覆盖，避免破坏后续人工修改。
- `data/evaluation/public-v2-draft/`：被 Git 忽略的逐题草稿、开发/评测分组、原题检查记录。
- [机器记录](evidence_revision_v2.json)：原题及草稿 SHA-256、代码 SHA-256、计数和范围限制，不含逐题原文。

从项目根目录运行：

```bash
python scripts/build_evidence_revision.py
python scripts/build_review_packet.py
python scripts/serve_review_packet.py
python -m pytest -q -p no:cacheprovider --tb=short
```

打开本地 `http://127.0.0.1:8768/review.html`。

下一步应在开发集分析漏召回，验证是否需要相邻块扩展或重排序，再另建未用于调参的题集。若要保留曲线趋势类题目，需要真正增加图像证据及视觉评测；当前改题仅让文本回归集更匹配文本索引能力。
