# 第三轮：60题逐题医学证据复核

日期：2026-09-20。执行者为 AI 助手；未冒充医生，未记录真实审核者姓名，人工/医学专家认证数为 0。本轮直接核对全部 60 道 v2 候选题的标注文字，针对疑点读取相邻页，视觉检查 3 页原始 PDF，并查阅 6 个权威外部来源。不是全面医学文献系统综述，也没有把模型自评分当审核结论。

## 结果

| 结论 | 题数 | 含义 |
|---|---:|---|
| 在来源限定范围内保留 | 31 | 当前核对未发现需要改动题目/答案的实质问题；非临床正确率认证 |
| 修订后列为回归候选 | 26 | 补条件、缩小外推范围、修正措辞或补齐证据标签 |
| 暂缓评分 | 3 | 公式索引损坏、原文单位疑点、临床来源需更新 |
| 合计逐题复核 | 60 | 每题均有独立中文理由和来源定位 |

相对 v2 实际改动 27 题：26 道修订候选，加上暂缓项中已补正参考公式的 1 题。得到 **57 道来源限定的 AI 复核回归候选、3 道暂缓题**。57 不是准确率、通过率或人工审核数。这一版本已见过旧评测结果，不能作为独立盲测集。所有 `reviewed` 保持 false，并新增单独的 AI 复核状态。

## 主要发现与处理

- **下腔静脉（s051）**：原片段漏了同章自主呼吸成人范围，以及后文“不能孤立用于补液决策”的限制。补充已有索引内的 3 条证据标签并修订答案，未引入检索器拿不到的外部答案。
- **半值层（s023，暂缓）**：原题要求两点计算，答案却只说使用两点公式。视觉核对 PDF 后补齐公式，但原索引中的公式顺序损坏，因此先暂缓文本回答评分，待公式入库修复。公式不是自动 OCR 的可靠输出。
- **视野容差（s028，暂缓）**：PDF 原页将 nominal area 与 SID 长度百分比相连，量纲及步骤措辞有疑点。保留原文记录，不自行猜测正确标准；待勘误或医学物理专业确认。
- **附件扭转（s045，暂缓）**：旧教材有绝对排除/肯定表述。ACOG 对青少年明确指出，术前不能只靠临床或影像标准确诊，Doppler 也不能单独指导决策。本轮不能将教材体积阈值推广为通用诊断标准，外部建议另存而未混入现有索引答案。[ACOG 原文](https://www.acog.org/clinical/clinical-guidance/committee-opinion/articles/2019/08/adnexal-torsion-in-adolescents)
- **肝血管瘤（s053）**：去掉超出形态比较问题的“无需随访”泛化。EASL 的随访结论有典型病灶等前提；异常肝背景/肿瘤病史也影响进一步影像评估。本题改为教材描述的形态与病例比较。[EASL 2016 指南](https://easl.eu/wp-content/uploads/2016/10/EASL-CPG-on-Management-of-benign-liver-tumours.pdf)
- **探头维修（s043）**：删除所有探头不可维修的概括。厂家存在认证维修服务，但这不证明教材中某一具体型号或某一种损坏必定可修。[Siemens 官方服务](https://www.siemens-healthineers.com/en-uk/ultrasound/transducer-repair-replacement)
- **胎盘定位（s048）**：将“最佳技术”改成特定图注的切面描述。RCOG 2026 更新涉及经阴道超声在定位胎盘和宫颈评估中的角色，旧图注不足以建立普遍首选结论。[RCOG 更新说明](https://www.rcog.org.uk/news/rcog-publishes-update-to-clinical-guidance-on-placenta-praevia-and-placenta-accreta-spectrum/)
- **HL7（s015）**：将版本流行度限定在 2014 教材历史语境；CDA 是临床文档标准，不能与整个 HL7 消息体系混为一谈。[HL7 CDA 定义](https://hl7.org/cda/)
- **主动脉测量（s052）**：保留 v2 对壁面和方向的区分；NICE 的测量框架同样说明约定需要明确，不能跨约定直接混用尺寸。[NICE 测量证据](https://www.nice.org.uk/guidance/ng156/evidence/b-imaging-techniques-to-diagnose-abdominal-aortic-aneurysms-pdf-7087991151)

其余逐题处理包括：小信号近似条件、方形采样单元假设、CT行宽配置、质控容差适用章节、清洁剂厂家认可要求、图例个案不外推、设备回放步骤不泛化等。s017 的 PDF 公式表示选中阳性反应的概率，删除了原答案中反向解释该概率的句子。

## 外部资料访问边界

HL7 和 Siemens 官方页面已直接打开。ACOG、EASL、NICE 的相关结论主要来自官方页面的搜索索引摘录；直接打开部分页面失败，未声称阅读全文。RCOG 阅读了官方更新摘要及指南入口，未完成新版全文审读。来源清单记录访问方式和范围，绝不将“查到摘要”写为“完整验证最新版指南”。外部核对仅服务于发现风险和限定题目范围，未把未入库内容偷偷变成生成模型的必答知识。

## 数据与可追溯性

逐题文件均位于 Git 忽略目录 `data/evaluation/medical-review-v3/`：

- `review_ledger.md`：便于阅读的60题复核理由、修订后题目/答案和引用。
- `review_ledger.json`：逐题决定、输入哈希、来源页、外部来源键、改动字段及暂缓原因。
- `all_candidates.json`：完整60题v3版本。
- `regression_candidates.json` / `held_candidates.json`：57道候选 / 3道暂缓题。
- `external_sources.json`：6个外部来源及访问范围。

[机器汇总](medical_review_v3.json)记录数量、输入输出哈希及范围。本轮没有新增 DeepSeek 调用，不产生新增模型 API 用量；网页查询不计入 DeepSeek 账单。未重新生成系统回答，不能计算新的回答质量提升。v1/v2 文件和历史成绩均保持不变。原有人工审核导入机制继续保留，AI 记录不会自动升级成人工决定。
